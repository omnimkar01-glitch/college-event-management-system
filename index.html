About the Project

Smart Event Registration for College Activities

This project digitizes common college event activities by bringing event publishing, student registration and participant tracking into one web-based platform.

It is designed for academic events, technical competitions, cultural programs, sports, workshops, seminars, placement activities and alumni interactions.
